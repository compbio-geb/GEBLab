Teaching

Our courses teach students to ask a biological question, find public data that can answer it, and analyze that data themselves.

DATA 405 / BIOL 480: Genomic Data Science

Fall 2025, Fall 2026. Python and R for genomic data, probability and statistics, and a student-designed research proposal on public data. Course site: Python & R for Genomic Data Science.

BIOL 419 / BIOG 419: Bioinformatics

Spring 2024, 2025, 2026. Hypothesis-driven analysis of public genomic datasets: each student develops an observation, a testable hypothesis, a study design and an analysis plan.
